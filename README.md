# Exercicio de If, Else e Loop em Python

Estudo em Python para praticar entrada de dados, condicionais e repeticao com confirmacao de senha.

## Visao geral

Este repositorio registra uma aula/exercicio de logica de programacao. O script coleta informacoes pelo terminal, calcula idade aproximada e usa `while` para repetir a confirmacao de senha ate que os valores informados coincidam.

## Problema resolvido

O exercicio demonstra como usar condicionais e loops para validar entradas simples em um fluxo interativo.

## Principais funcionalidades

- Entrada de nome, sobrenome, cidade, profissao e ano de nascimento.
- Calculo de idade com base em ano fixo usado no exercicio.
- Confirmacao de senha.
- Repeticao enquanto os valores nao forem iguais.
- Exibicao de resumo no terminal.

## Como funciona

O usuario informa os dados solicitados e cria uma senha. O programa solicita confirmacao e repete a pergunta enquanto a confirmacao nao corresponder ao valor original.

## Tecnologias utilizadas

- Python
- Linha de comando
- Replit identificado por arquivos do repositorio
- Poetry identificado por `pyproject.toml`

## Arquitetura

Projeto simples com um unico script principal.

## Estrutura do projeto

- `main.py`: script com entrada de dados, condicional e loop.
- `pyproject.toml`: configuracao Python/Poetry.
- `poetry.lock`: lockfile de dependencias.
- `replit.nix` e `.replit`: arquivos de ambiente Replit.
- `venv/`: ambiente virtual versionado no repositorio.

## Status

Projeto de estudo. Serve como registro de pratica inicial com `if`, `else` e `while`.

## Limitacoes conhecidas

- Nao deve ser usado como cadastro real.
- Nao possui persistencia de dados.
- O script contem trecho solto ao final e pode exigir ajuste se for executado diretamente.
- O ambiente virtual esta versionado no repositorio.
